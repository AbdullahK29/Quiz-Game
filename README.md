# 🎯 Interactive Quiz Game

A simple and fun **Interactive Quiz Game** built using HTML, CSS, and JavaScript.  
Test your knowledge and get instant feedback on your answers!

---

## 🚀 Features

- Multiple choice questions
- Real-time score tracking
- Progress bar indicator
- Instant correct/incorrect feedback
- Final result with performance message
- Restart quiz functionality

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
